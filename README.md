# Credit Appraisal and Risk Analysis of Nitin Spinners Ltd.

## Overview

This project focuses on the financial and credit risk analysis of Nitin Spinners Ltd. using Excel, SQL, and Power BI. The analysis evaluates the company's financial health, creditworthiness, risk indicators, and peer performance through interactive dashboards and ratio analysis.

## Tools Used

* Excel
* SQL
* Power BI

## Key Analysis Performed

* Financial statement analysis
* Ratio analysis
* Altman Z-Score evaluation
* Credit rating assessment
* Peer comparison analysis
* Risk trend visualization
* Interactive dashboard reporting

## Dashboard Features

* Financial KPI tracking
* Liquidity and solvency analysis
* Profitability ratio visualization
* Credit risk indicators
* Comparative company performance dashboards

## Files Included

* Excel workbook
* SQL export file
* Power BI dashboard (.pbix)
* Dashboard screenshots

## Project Objective

The objective of this project is to analyze the creditworthiness and financial stability of Nitin Spinners Ltd. by combining financial analysis techniques with data visualization and business intelligence tools.
